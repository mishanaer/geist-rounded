# Geist Rounded

A fan-made rounded version of [Geist by Vercel](https://github.com/vercel/geist-font). Softer corners and stroke endings, with the original proportions and character. Not an official Vercel release.

Nine weights (100–900), 975 glyphs, Latin and Cyrillic, and 11 stylistic sets. Variable and static TTF/WOFF2 files. Upright styles only.

**[Try and download the font](https://mishanaer.com/ui/geist-rounded)**

```text
Use Geist Rounded as the main interface font in this project. Download and self-host the variable WOFF2 file:
https://mishanaer.com/ui/geist-rounded/fonts/GeistRounded.woff2

Load it with @font-face: font-family "Geist Rounded", font-weight 100 900, font-style normal and font-display swap. For Next.js, use next/font/local instead.
```
